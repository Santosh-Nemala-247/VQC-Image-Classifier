VQC Image Classifier

A lightweight Visual Quality Classification (VQC) application that classifies images into predefined quality categories using a deep learning model. The application provides an intuitive web interface for uploading images and instantly predicting their quality class.

#🚀 Features

📷 Upload an image for classification
🤖 Deep learning-based image quality prediction
⚡ Fast and accurate inference
🎨 Simple and responsive user interface
📊 Displays predicted class with confidence score
🔄 Supports multiple image formats (JPG, JPEG, PNG)

#🛠️ Tech Stack

Frontend: React.js
Backend: Python (Flask/FastAPI)
Deep Learning: TensorFlow / Keras
Image Processing: OpenCV, NumPy
Visualization: Matplotlib
